This file is for development purposes only and provides field definitions for filling the screen in the OpenTX Companion Simulator. Users do not need this file on their handset's SD card!

### Using
Copy the entire mockup directory into the same directory as `elrsV2.lua` on your hard drive where you've set the OpenTX Companion "SD Structure Path". The SD structure path should look like this:
```
SCRIPTS/TOOLS/elrsV2.lua
SCRIPTS/TOOLS/mockup/elrsmock.lua
SCRIPTS/TOOLS/mockup/README.md <- this file
```
When you execute elrsV2.lua, the screen will be populated with fake ELRS Lua config fields.

### Spectrum analyzer

`parseSpectrumMessage()` in `elrs.lua` is a hand-written decoder for the spectrum wire
format, and the simulator is the only place it can be checked against the firmware encoder.
`spectrummock.lua` is a fake TX that replays `spectrumgolden.lua` — frames generated by the
real `SpectrumEncodeFrame()` — through the normal click → plot → exit path. Use a B&W
profile (colour handsets do not show this view); go to `Spectrum` → `Start Scan` and check
that bin 1 reads 2400.4MHz, the ramp has a 3-bin gap at bin 40, and RTN closes the plot
for good.

Regenerate the golden file after any wire-format change (the pinned frame in
`test/test_txspectrum/` fails if you forget):
```
cd src/lua/mockup
g++ -I../../lib/SpectrumSweep -o gen_spectrumgolden gen_spectrumgolden.cpp
./gen_spectrumgolden > spectrumgolden.lua
```
